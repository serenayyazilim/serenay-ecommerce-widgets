# Security Policy

## Supported versions

Only the latest published version on
[pub.dev](https://pub.dev/packages/serenay_ecommerce_widgets) receives
security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use GitHub's
[private vulnerability reporting](https://github.com/serenayyazilim/serenay-ecommerce-widgets/security/advisories/new)
for this repository. We'll acknowledge the report and follow up with next
steps as soon as possible.
